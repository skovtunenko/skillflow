Why the language exists

A flow file states intent. Nothing executes it. Most workflow languages are imperative or need a runtime. A skill is a prompt, which Andrej Karpathy calls Software 3.0, mixed with code, so each node of a flow names who acts.

SKILL.md
Run `scripts/collect.sh <tag>`. If it exits with a non-zero code, the tag does not exist: tell the user and stop.

Modes

Tokens go only to the modes that need judgment. Your agent runs them as a skill. Drawing the graph and editing the flow by hand run as a script: the same flow gives the same result, with no tokens.

Install

Adds SkillFlow to Claude Code, Codex, Cursor, and more, through skills.sh or kasetto. Needs Node.js 22 or later.

Then type skillflow help in your agent.

npx skills add skovtunenko/skillflow
kst add https://github.com/skovtunenko/skillflow --skill skillflow --project
git clone https://github.com/skovtunenko/skillflow
cp -R skillflow/skills/skillflow <skills-folder>/

Basic principles

  1. One flow file describes exactly one skill.

    flow.kdl↔release-notes/SKILL.md · scripts/ · references/

  2. The flow file is the source of truth; the skill implements it.

    flow.kdl→release-notes/

  3. Sync works in both directions: flow to skill, or skill to flow.

    flow.kdl⇄release-notes/

  4. A flow states intent: steps, decisions, data, dialogue with the user, invariants, and failures, without low-level detail.

  5. Each step and decision names who acts: by=llm, by=code, or by=human.

    llmcodehuman

context

Facts about the whole skill.

phase

A named group of steps.

step

One action, and who does it.

decide + when

A fork of the path; each when is one outcome.

gate

A person approves; approved and revise are implied.

catch

What happens when a step fails.

end

An early exit: the flow stops here.

invariant

A rule for the whole flow, and who keeps it.

Why KDL

A flow file is a KDL 2.0.0 document.

  • The skeleton is data

    A parser returns the tree; the validator checks it.

  • Intent stays in strings

    Names hold the structure; strings hold the intent.

  • Mistakes fail loudly

    The parser rejects almost-right text, like true from KDL 1.

  • Nothing to install

    SkillFlow ships its KDL parser, with no dependencies.
