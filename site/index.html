What SkillFlow is

SkillFlow is an intent-driven DSL: a declarative language for the intent of an agent skill. It is made for skills, not for general workflows. The flow file is the specification; the skill implements it.

Select a node or a line to see its pair, or an executor to see its steps.

Why the language exists

Most workflow languages are imperative, or need a runtime that executes them. SkillFlow is neither: a flow file states intent, and nothing executes it.

Andrej Karpathy calls programs written as natural-language prompts Software 3.0. A skill is such a program, combined with deterministic code. In a flow, each node names who acts.

Basic principles

  1. One flow file describes exactly one skill.
  2. The flow file is the source of truth; the skill implements it.
  3. Sync works in both directions: flow to skill, or skill to flow.
  4. A flow states intent: steps, decisions, data, dialogue with the user, invariants, and failures, without low-level detail.
  5. Each step and decision names who acts: by=llm, by=code, or by=human.

The language by example

ExecutorWho acts
by=llmthe model, subagents included
by=codea bundled script or a fixed command whose result needs no judgment
by=humanthe user, who decides or acts

context

Facts about the whole skill.

phase

A named group of steps.

step

One action, and who does it.

decide + when

A fork of the path; each when is one outcome.

gate

A person approves; approved and revise are implied.

on-fail

What happens when a step fails.

end

An early exit: the flow stops here.

invariant

A rule for the whole flow, and who keeps it.

Start

Copy the folder skills/skillflow of the repository into the skills folder of your agent. It needs Node.js 22 or later; no packages, no network.

Then ask the agent skillflow help, or run <skills-folder>/skillflow/skillflowctl page <skill> yourself.
